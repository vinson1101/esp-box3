# ESP-BOX-3 EZ 技术计划

当前分支 `codex/esp-box3-ez`，版本 `2.5.3-box3-ez.28`。版本能力、构建方法和测试边界见 [版本说明](releases/esp-box3-ez-28.md)。

## 架构与实施约定

BOX-3 负责本地唤醒、采音/VAD、播放、屏幕和传感器。EZ 管理终端配对、ASR/TTS 和助理会话；设备使用当前助理会话，不创建独立云端小智账号或固定会话 ID。
设备、录音流、播放流和应用任务分别管理生命周期。取消播放不等于取消 Agent Run；迟到取消通知不能清除新录音；按物理流/连接代际隔离旧结果，按协议确认点释放录音缓存。单个音频段结束不等于整轮回答结束。
保留换网入口，不硬编码 Wi-Fi、EZ 主机地址、端口、身份或 Provider 凭据。网络和配网变更与语音修复分开验收。

## 当前实施状态

| 模块 | 状态与边界 |
|---|---|
| 配网、发现、配对 | 本地唤醒/热点配网、发现与认证已实现；发现回退和重试保留；历史偶发断连仍需复现 |
| 采音结束 | VADNet 确认静默后提交；VAD 状态重置及连续 PCM 首音去重已修复；真实噪声环境需要人工验收 |
| 连续对话与打断 | 回复排空后本地续听，约 5 秒无开口退出；Boot 打断和旧代际清理已实现 |
| 主页 | 官方球形机器人视觉参考、状态动画；回复正文换行与自动上下滚动，保留中文 Noto 20px |
| 第二屏 SENSOR | 已迁移温湿度/CRC和雷达活动监测；仅页面可见时采样，缺失/错误明确提示，不将无数据解释为零 |
| 最后一屏媒体/音量 | 本地音量条、加减、边界与持久化已实现；音乐播放/切歌需要真实音源和音频仲裁后再接入 |
| ASR/TTS | EZ 侧配置；Paraformer HTTP/WAV 到官方 WebSocket 的本机适配器已实现；密钥独立私有配置 |

三屏左右滑动，不设占据正文空间的底部菜单。以后新增页面插在媒体/音量页之前，媒体页一直保持最后。

## 后续计划

1. 人工验证首字、首次唤醒、续听、长文完整播放及 Boot/唤醒词打断；保留关闭码、TLS 和心跳诊断，遇到历史偶发问题再定位。
2. 验证 SENSOR 实际芯片、温湿度精度、雷达活动/保持状态、页面进出与语音并发。雷达首版只显示活动，不接管系统休眠。
3. 红外学习与发送作为独立阶段：学习遥控器开/关、持久化、重学与真实设备控制，当前不启用。
4. 核对并引入 Mute 按钮、前面板返回触摸键等交互；区分硬件隐私静音与软件对话打断。
5. 保留官方 Emote 双眼、出厂麦克风柱条、默认 PNG 等独立动画选项，先核对授权、资源预算和状态映射，再替换或扩展视觉。
6. 原厂其他扩展能力、媒体音源和电源/休眠在独立阶段按实际硬件启用；不将最新 BSP 所有能力视为本机已具备。
