# ESP-BOX-3 EZ `.28`

专用于 ESP32-S3-BOX-3 连接本机 EZ 助手的固件，分支 `codex/esp-box3-ez`。版本 `2.5.3-box3-ez.28`。
固件基于 `78/xiaozhi-esp32` 的硬件、音频与显示基础，终端认证/PCM 协议参考 `vinson1101/agent-robot`，官方界面和传感器实现参考乐鑫项目；保留原有许可证和来源。

## 当前能力

- 本地唤醒词 Hi, ESP；通过 mDNS 发现 EZ，以 TLS 证书指纹和设备签名认证，支持配对及原身份重连。
- 16kHz 单声道 PCM16，20ms 传输帧；VADNet 确认静默后封口，首次未开口及回复后的续听窗口约 5 秒，单段录音上限 60 秒。
- 修复连续 AFE 输出再次补入历史 VAD cache 的首音重复路径；保留连续 PCM、VAD 状态同步和续听预录。没有删除重复文字来掩盖音频问题。
- 单击 Boot 可切换/打断对话，长按约 3 秒进入热点配网；换网、配对身份和本地音量保存在设备 NVS。
- 三屏左右滑动：机器人/对白主页、SENSOR、媒体/音量。主页使用官方机器人视觉参考，回复正文支持换行与自动滚动；音量页固定在最后，支持本地调节和持久化。
- SENSOR 第二屏仅在可见时采样：温湿度、CRC/读取异常、雷达自检与活动状态。使用独立 I2C0，与音频/触摸总线隔离。未连接时保持文字提示，连接后使用官方布局及图标，中文使用 Noto 20px。
- 红外学习/发送尚未启用，页面只解释用途；雷达表示活动信号，不承诺人体数量、距离或静止人体识别。

## 构建

使用 ESP-IDF 6.1；不要依赖默认语言和唤醒词：

```sh
python scripts/build.py espressif/esp32-s3-box-3 --name esp-box-3-ez --language zh-CN --wake-word hiesp
```

本地唤醒变体 `esp-box-3` 仅用于兼容检查。本分支部署到设备的是 EZ 变体。
ASR/TTS 在 EZ 中配置；Paraformer 本机协议适配见 [接入说明](../../scripts/ez_speech/README.md)。真实凭据、Wi-Fi 密码、配对私钥和设备 NVS 不属于源码。

## 验证与边界

- 两种 BOX-3 变体构建通过。EZ 应用约 3.30 MB，应用分区约剩 20%；仅写应用分区，资源和设备配置保留。
- 主机检查 157 项，4 项因可选依赖缺失跳过；最终 UI/传感器差异追加 3 项检查通过。真实 LVGL 覆盖三屏、音量、未连接/异常、自检与活动状态。
- 生产 AFE→PCM 分帧→WAV→实际 ASR 适配器解码的合成数据路径逐样本保持一致；旧代码重复路径已离线复现，修复后通过。
- 一轮人工测试的日志记录 13 次采音，12 次输入接收、1 次可恢复空识别；2 次 Boot 打断后的旧代际播放帧被正确丢弃。其余 10 轮回复完成排空，观察期间没有连接掉线、播放队列溢出或崩溃；70 次心跳正常，最大应答 14ms。
- 这些日志不包含原始音频或对白，不能仅据此确认所有首字识别、真实听感或每次静默时长。底座实际读数、精度、雷达灵敏度及并发语音的实机验收仍需单独确认。
- 历史偶发连接关闭、长文断音保留为待复现问题，本版不宣称全面解决。没有修改 EZ Runtime，不包含 Runtime 60 字分段补丁的部署。
